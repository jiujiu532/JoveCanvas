# Open-source license

JoveCanvas is licensed under the GNU Affero General Public License v3.0 (AGPL-3.0). You may use, copy, modify, and distribute the project as long as you comply with the license.

## Intent

JoveCanvas stays open source so people can inspect and change the code, avoid being locked to a fixed API vendor, connect their own APIs and model channels, and organize prompts, references, assets, and outputs on a canvas into workflows that fit them.

## Usage guidance

For local learning, research, or personal use, follow the open-source license directly.

If you plan commercial products, private delivery, SaaS, or long-lived internal team systems, confirm that your usage still satisfies AGPL-3.0.

If you cannot open-source modified code, or you need closed-source delivery, commercial licensing, private deployment support, or custom development, see [Business cooperation](/en/docs/business/business).

## What AGPL-3.0 means (plain language)

- **Source obligation**: If you use JoveCanvas AGPL code—however you or your downstream use, modify, rework, or distribute it—you must make the complete resulting code available, not only the diffs, and not by claiming a rewrite “breaks the link” to the original.
- **Copyleft continuity**: Derivatives must stay under AGPL-3.0; you cannot relicense that code as proprietary.
- **Network use counts**: Even if you only run a modified version as a website, SaaS, or other network service, users of that service must be able to obtain corresponding source under AGPL-3.0.
- **Keep notices**: Do not strip author info, copyright, license notices, or attribution.
- **No extra restrictions**: You cannot add restrictions that forbid redistribution of the AGPL code or require buying a product/service merely to use that open-source code.
- **Disclaimer**: Software is provided as-is; authors do not warrant it is bug-free and are not liable for results, losses, or risks from using the project.

Closed-source commercial use of this project is not allowed under AGPL. If you want commercial use of JoveCanvas, respect open source: comply with AGPL-3.0 and keep corresponding code open.
