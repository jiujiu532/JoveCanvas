# Canvas shortcuts

Common mouse and keyboard actions on the canvas.

## View

- Drag empty canvas: pan.
- Mouse wheel: zoom.
- Zoom slider: precise zoom.
- Reset view: default zoom and center.

## Selection

- `Ctrl / Cmd` + drag: box-select multiple nodes.
- `Shift / Ctrl / Cmd` + click node: add or remove from selection.
- `Ctrl / Cmd` + `A`: select all canvas nodes.
- `Esc`: clear selection and close open overlays.

## Edit

- `Ctrl / Cmd` + `C`: copy selected nodes.
- `Ctrl / Cmd` + `V`: paste nodes.
- `Delete / Backspace`: delete selected nodes or edges.
- `Ctrl / Cmd` + `Z`: undo.
- `Ctrl / Cmd` + `Shift` + `Z`: redo.
- `Ctrl / Cmd` + `Y`: redo.

## Images and assets

- Drop image files: upload onto the canvas.
- Import image button: pick local images.
- My assets: insert selected assets onto the canvas.

## Undo / redo scope

History covers nodes, edges, viewport, background mode, and assistant session changes. Project name, account state, global AI settings, and “My assets” save actions are outside the current canvas history.
