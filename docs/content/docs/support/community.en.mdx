## Get involved

- Star the GitHub repository so others can discover the project.
- File reproducible Issues with redacted details.
- Contribute docs, tests, channel adapters, or small fixes.
- Before code contributions, read root `CONTRIBUTING.md`, `AGENTS.md`, and `CLA.md`.
