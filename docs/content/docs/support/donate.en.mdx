# Donate

If JoveCanvas helps you, consider supporting maintenance via QR donation, a GitHub Star, or AI subscription account support.

Development relies heavily on tools such as Codex and Claude for coding, debugging, and documentation. Those tools are paid. Donations primarily fund AI developer tools, model services, and related maintenance so the project can keep shipping.

## Ways to support

Including but not limited to:

- Star the GitHub repository so more people can discover the project.
- Monetary donations for AI tool subscriptions, model services, and maintenance costs.
- Sharing Codex / Claude (or similar) subscription access so maintainers can keep using AI-assisted development.
